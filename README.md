# A simple Java Bank Application
### Written and Developed by cntavelidis@nyc.gr for university

The above is a basic Java bank application written in Java 26. It supports persistent
log term account data and transaction logging. It is licensed under the
GNU/General License V3 (GPLv3). 

The PlantUML directory contains .puml files for the sequence and usecase
UML diagrams. These are to be generated using PlantUML's IntelliJ IDEA Plugin.

## Dependencies
* Java 26>=

**IMPORTANT**: This was originally written using the JetBrains IntelliJ IDEA 
IDE and whilst it has been exported to Eclipse using IDEA's built-in exporter,
it is not guaranteed to properly work with Eclipse. You have been warned
and are recommended to use IDEA.
